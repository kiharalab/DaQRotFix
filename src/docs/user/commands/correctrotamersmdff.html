correctrotamers mdff

correctrotamers mdff structure map [radius angstroms] [coordinateUpdates count] [backboneSpringConstant kJ mol-1 A-2] [outlierThreshold P-value]

Snapshot the initial ISOLDE rotamer-outlier list and optimize each residue in turn. Canonical targets are tried in decreasing expected probability. Every trial starts from the coordinates accepted before that residue, receives a short local ISOLDE MDFF minimisation, and is assessed by the number of rotamer outliers in the local protein region.

The first target with zero local outliers is accepted. If no target reaches zero, the target with the fewest local outliers is accepted, with decreasing probability as the tie-breaker. Rejected-trial coordinates are restored. Backbone N, CA, C and O atoms are temporarily position-restrained; side chains remain mobile. The map must already have an enabled ISOLDE MDFF manager. The default outlier threshold is the current ISOLDE cutoff (normally 0.0005, equivalent to 0.05%). The active local region is automatically selected and focused while each MDFF trial runs.
