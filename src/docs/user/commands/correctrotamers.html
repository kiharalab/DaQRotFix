correctrotamers

correctrotamers structure map

Correct the ISOLDE rotamer outliers present at command start. Every canonical target is constructed from the same original coordinates, checked by ISOLDE rotamer validation, and scored by the mean map value at side-chain heavy-atom centres. Out-of-map targets are rejected. The highest-density valid target is applied without using rotamer probability as a ranking term.

The map must already have an ISOLDE MDFF manager for the structure. The command uses that association only as a prerequisite check. It does not start, pause, or minimize an ISOLDE simulation and does not modify MDFF state or restraints.
